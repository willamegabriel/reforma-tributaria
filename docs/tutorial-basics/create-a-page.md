# Natureza de Operações

Na Natureza de Operações, a única alteração realizada foi a inclusão do Tipo de Operação. As mudanças são:

- Inclusão de um novo campo chamado Tipo de Operação no cadastro de Natureza de Operações.

- Esse campo passa a listar todos os tipos previamente cadastrados no sistema e permite vinculá-los diretamente à Natureza de Operações, refletindo automaticamente nos produtos os valores configurados de IBS e CBS.
